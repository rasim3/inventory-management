Architecture Overview

Factory Inventory Management System

A two-tier demo app. A Vue 3 single-page app talks over REST to a FastAPI service. The service loads JSON files into memory at startup and does all filtering in Python. There is no database, no authentication, and nothing is saved between restarts.

Data flow: applying a filter

The main interaction. Changing a filter in the top bar re-queries the API and re-renders the derived data.

  1. components/FilterBar.vue → composables/useFilters.js

    User picks a filter

    Time Period, Warehouse, Category or Order Status. These are singleton refs at module scope, so every view shares the same filter state.

  2. views/*.vue

    View reacts

    The active view watches the filter refs and calls getCurrentFilters(), which maps the period to month (e.g. 2025-03 or Q1-2025).

  3. src/api.js

    Request is built

    Values of 'all' are left out and the rest become query params: GET /api/orders?warehouse=…&status=…&month=Q1-2025.

  4. server/main.py

    FastAPI filters in memory

    apply_filters() runs case-insensitive matches on warehouse, category and status. Then filter_by_month() substring-matches order_date, expanding quarters through QUARTER_MAP.

  5. Pydantic response_model

    Validated and serialized

    Lists are checked against InventoryItem, Order and the other models before being returned as JSON.

  6. views/*.vue

    Rendered through computed properties

    Raw responses go into refs (allOrders, inventoryItems). Totals, chart series and KPI cards are computed, so the UI updates on its own.

Things to know

Gaps between the frontend and backend that I found while reading the code.

The frontend calls endpoints that don't exist api.js defines /api/tasks (GET, POST, PATCH, DELETE) and /api/purchase-orders, and the Tasks modal in App.vue calls the tasks endpoints. Neither is implemented in main.py, so those calls return 404. CreatePurchaseOrderRequest is defined but no route uses it.
Backlog view is not routed views/Backlog.vue exists but isn't registered in main.js. Backlog data only appears on the Dashboard.
Several filters are not applied everywhere total_backlog_items on the dashboard ignores every filter. Spending, demand, backlog and reports endpoints accept no filters, even though the filter bar is shown on every page.
Quarters are hard-coded to 2025 QUARTER_MAP and the quarterly report only know 2025. Dates are matched as substrings, so month=2025-1 would also match October to December.
Demo-only settings The API base URL is hard-coded to localhost:8001, in api.js and again in Reports.vue. CORS is * with credentials. Auth is a stubbed user in useAuth.js. The only thing persisted anywhere is the locale, in localStorage.
